## 开发说明
### 顶层目录说明
```sh
- .cargo文件夹 : 编译器配置
- assets文件夹 : 资源文件
- docs文件夹 : 文档
- examples文件夹 : 示例代码
- files文件夹 : 其他资源文件
- result文件夹 : 代码运行结果
- src文件夹 : 源码目录
- static文件夹 : 封印为静态文件的库
- target文件夹 : 编译产物
- tests文件夹 : 单元测试
- vendor文件夹 : 所有依赖库
- `问题记录`文件夹 : 问题问答记录
* build.rs : 编译前预处理
* Cargo.toml : 项目配置
* clippy.toml : 代码风格规范
```
